# YouTube Shorts Creator

## Goal
Extract high-impact micro-snippets into 45-second vertical (9:16) video scripts engineered for high retention and seamless infinite looping.

## Step-by-Step Instructions
1. Select 1 key technical takeaway or agent demonstration.
2. Draft script with immediate 1-second visual hook and fast-paced audio cadence.
3. Design last sentence to seamlessly connect back into the first sentence for infinite loop playback.
4. Output Shorts script artifact.
