# YouTube Growth Analytics

## Goal
Perform post-launch performance audits on published videos, analyze retention drop-off points, and repurpose high-performing video scripts into developer newsletter articles.

## Step-by-Step Instructions
1. Analyze 30-second viewer retention rate (>65% goal) and identify key drop-off timestamps.
2. Formulate editing/pacing recommendations for upcoming videos based on audience retention curves.
3. Repurpose technical script content into markdown tech newsletter format.
4. Output growth analytics report artifact.
