# YouTube AI Production

## Goal
Generate high-CTR visual thumbnail image prompts (Midjourney/Flux 16:9) and voice synthesis direction briefs (ElevenLabs SSML audio notes).

## Step-by-Step Instructions
1. Generate 3 visual thumbnail concepts using high-contrast color palettes (Deep Obsidian, Cyan, Neon Violet).
2. Formulate Midjourney / Flux prompts optimized for 16:9 ratio and clean text focal zones.
3. Draft voice direction SSML briefs (emphasis, pitch, pacing) for voiceover refinement.
4. Output asset prompts artifact.
