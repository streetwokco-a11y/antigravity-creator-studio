# YouTube Trend Research

## Goal
Track search velocity, developer sentiment, and viral momentum around AI coding tools (Google Antigravity, Gemini 3, Cursor, Claude Code, Devin).

## Step-by-Step Instructions
1. Monitor developer social signals, GitHub trending repos, and search query volume.
2. Identify breakout topics with >200% week-over-week velocity.
3. Produce a trend report artifact with recommended urgency scores.
