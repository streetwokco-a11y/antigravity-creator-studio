# YouTube Channel Ops

## Goal
Perform pre-upload operational quality assurance, audio normalization checks (-14 LUFS, peak < -1 dBTP), OBS PipeWire 60fps verification, and Content ID copyright safety.

## Step-by-Step Instructions
1. Audit audio file integrated loudness against YouTube target (-14.0 LUFS ±1.0 LUFS, -2.0 dBFS limiter ceiling).
2. Verify OBS video capture frame rate (locked 60 fps) and terminal font legibility (18px).
3. Check background music and code assets for Content ID safety.
4. Output Operational QA approval checklist artifact.
