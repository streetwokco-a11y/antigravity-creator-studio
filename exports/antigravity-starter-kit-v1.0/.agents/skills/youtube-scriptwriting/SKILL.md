# YouTube Scriptwriting

## Goal
Draft high-retention technical scripts featuring a dual-column format (Audio spoken track + Visual B-roll directive), 60-second opening retention hook, pattern interrupts every 60s, and strong CTAs.

## Step-by-Step Instructions
1. Write 60-second high-energy retention hook (verbal promise + visual multi-agent demo).
2. Format full script into 2 columns: Audio (Speech) and Visual (Screen Capture / B-Roll Cutaways).
3. Insert pattern interrupts and visual cue shifts every 45-60 seconds.
4. Output script artifact ready for recording.
