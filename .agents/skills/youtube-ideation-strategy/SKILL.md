# YouTube Ideation Strategy

## Goal
Construct a balanced content matrix dividing video concepts into 40% Search Intent (evergreen setup/tutorials), 40% Browse Intent (breakout comparisons/critiques), and 20% Shorts.

## Step-by-Step Instructions
1. Map high-volume evergreen queries (e.g., *"How to install Antigravity CLI on Ubuntu"*).
2. Formulate provocative browse titles (e.g., *"Antigravity Autonomous Agents vs Cursor AI"*).
3. Output content matrix artifact.
