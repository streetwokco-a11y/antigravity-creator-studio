# YouTube Master Pipeline

## Goal
Orchestrate the end-to-end 6-phase YouTube channel automation workflow from initial niche intelligence to post-launch analytics audit.

## Step-by-Step Instructions
1. **Phase 1 Intelligence:** Run `/youtube-niche-research`, `/youtube-trend-research`, `/youtube-ideation-strategy`.
2. **Phase 2 Content Production:** Run `/youtube-scriptwriting` and `/youtube-shorts-creator`.
3. **Phase 3 Asset Generation:** Run `/youtube-ai-production`.
4. **Phase 4 Packaging & SEO:** Run `/youtube-packaging-seo`.
5. **Phase 5 Operational QA:** Run `/youtube-channel-ops`.
6. **Phase 6 Post-Launch Audit:** Run `/youtube-growth-analytics`.
7. Consolidate outputs into a master video production plan artifact.
