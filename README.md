## 🛠️ Quickstart Guide

### 1. Launch Antigravity CLI
In your Ubuntu terminal, navigate to this workspace and run:
```bash
agy
```

### 2. Seed Workspace for Recording Demo
Inside the `agy` TUI / Mission Control prompt, run:
```
/youtube-dev-demo-prep
```
This will automatically wipe temporary test databases, seed realistic mock data, configure terminal font scaling (18px), scrub `.env` secrets, and stage 3 parallel agent demo tasks.

### 3. Run the End-to-End Pipeline
To trigger the full 6-phase automation workflow:
```
/youtube-master-pipeline
```

## 📹 Video #1 Production Requirements

- **OBS Studio Capture:** PipeWire Screen/Window Capture @ **60 fps**.
- **Audio Gain Staging:** Mic input peak -18 dB to -6 dB; OBS Limiter threshold set to **-2.0 dBFS**.
- **YouTube Audio Target:** Integrated loudness **-14 LUFS** (peak < -1 dBTP).
- **Opening Hook:** 60-second high-energy retention hook with split-screen parallel agent B-roll cutaway.
