# Product Requirements Document (PRD) - Developer YouTube Channel

## 1. Executive Summary & Vision
This channel delivers high-density, action-oriented coding tutorials, autonomous AI agent workflows, and modern Linux/Ubuntu software engineering practices. The goal is to build the premier technical YouTube channel for developers seeking to harness Google Antigravity, Gemini 3, and autonomous agent orchestration.

---

## 2. Business Objectives & Revenue Metrics
- **Target Monetization RPM:** **$22.00 – $38.00+ USD** (Software Engineering / AI Tooling / Cloud Infrastructure vertical).
- **Target Audience:** Senior software engineers, fullstack developers, DevOps engineers, tech leads, AI researchers, and Linux power users.
- **Key Performance Indicators (KPIs):**
  - **Subscriber Growth Goal:** 10,000 subscribers within 90 days.
  - **30-Second Retention Rate:** > 65% across all main videos.
  - **Average Percentage Viewed (APV):** > 50% for 10-15 minute deep-dive tutorials.
  - **Click-Through Rate (CTR):** > 8.5% on primary 16:9 packaging.

---

## 3. Visual & Creative Brand Guidelines
- **Color Palette:** Sleek dark mode (Deep Obsidian `#0d1117`, Cyan Electric `#58a6ff`, Violet Neon `#bc8cff`, Energetic Amber `#f0883e`).
- **Typography:** Inter / JetBrains Mono for clean code readability. Minimum on-screen code font size of **18px**.
- **Pacing & Editing:**
  - **0-60s Retention Hook:** High-energy visual or bold statement (e.g. *"Stop treating AI like an autocomplete toy..."*).
  - **Pattern Interrupts:** Visual cutaway or camera shift every 45-60 seconds.
  - **B-Roll Integration:** Real-time multi-agent execution in Mission Control, terminal animations, screen splits.

---

## 4. Content Strategy Matrix

### Search Intent vs. Browse Intent
- **Evergreen Search (40%):** Practical setup guides (e.g., *"How to Install Antigravity CLI on Ubuntu 24.04"*).
- **Viral Browse / Hype (40%):** Breakthrough comparisons (e.g., *"Antigravity Autonomous Agents vs Cursor AI: The Real Test"*).
- **Shorts / Micro-content (20%):** 45-second vertical loops highlighting mind-blowing agentic coding tricks.

---

## 5. Video #1 Deliverable Specification
- **Title:** *"Stop Using AI Like an Autocomplete Toy (Antigravity Agentic Setup)"*
- **Primary Goal:** Show 3 parallel agents building, testing, and containerizing a fullstack app in under 60 seconds.
- **Hook Script:**
  > *"Stop treating AI like an autocomplete toy. If you're still typing every line of code into VS Code, you're working in the past. Today, we're unleashing three autonomous AI agents executing in parallel inside Google Antigravity..."*
- **Call-To-Action (CTA):** Clear prompt to subscribe and download the `.agents/skills` repository pack.
